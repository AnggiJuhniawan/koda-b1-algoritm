# Algoritma Perhitungan

## Deskritif

```
1. Mulai
2. Masukkan variabel A
3. Masukkan variabel B
4. Hitung Hasil dari A + B
5. Tampilkan Hasil
9. Selesai
```

## Flowchart

```mermaid
flowchart TD
    start((start))
    input1[/Input A/]
    input2[/Input B/]
    hasil[Hasil = A + B]
    output[/Tampilkan Hasil/]
    Finish(((end)))
    start --> input1 --> input2 --> hasil --> output --> Finish
```

## Pseudo-Code

```pseudo-code
DECLARE A : INTEGER
DECLARE B : INTEGER
DECLARE Hasil : INTEGER

INPUT A
INPUT B
Hasil <- A + B

OUTPUT "Hasil nya adalah ", Hasil
```
